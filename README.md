# First-Person EarthBound

A ROM hack that turns EarthBound (SNES) into a first-person 3D/2D hybrid: a 3D-rendered overworld seen through Ness's eyes, with 2D sprites for characters and objects.

Status: planning. See `docs/ROADMAP.md` and `docs/PROJECT_LOG.md`.

This repository contains no ROM data. The hack will be distributed as a patch you apply to your own legally obtained EarthBound ROM.
